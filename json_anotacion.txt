## Explicación 

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `instanceId` | int | ID de la instancia de examen |
| `author` | string | Email del profesor que corrige |
| `savedAt` | int | Timestamp (ms) del guardado |
| `textComment` | string | Comentario general del profesor |
| `strokes` | array | Lista de trazos dibujados |
| `strokes[].page` | int | Número de página (1-indexed) |
| `strokes[].points` | array | Coordenadas relativas (0-1) |
| `strokes[].color` | string | Color hex del trazo |
| `strokes[].width` | int | Grosor en px (2, 4, o 6) |
| `strokes[].timestamp` | int | Cuándo se hizo el trazo |
